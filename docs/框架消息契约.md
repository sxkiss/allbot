# 框架消息契约

> **本文件为全仓消息契约唯一事实源（SSOT）**。凡文档中涉及「消息字段、事件名、归一流程、路由分发、插件契约、适配器契约、facade 承诺 API」的表述，一律以本文件为准；本文件未列的符号、API、字段、事件不得写入其它文档。
>
> 依据现版代码（代码为唯一事实源，含 `e22c554` 群前缀修复）。术语统一为「框架统一归一」「通用出口 `other_message`」「纯 str 的 `Content`」。涉及归一字段与事件的教程、报告，统一链接回本文件。

## 阅读前必读：两个不能混为一谈的概念

| 概念 | 含义 | 出现位置 |
|------|------|----------|
| **归一器输入形状** | 适配器入队时、`MessageNormalizer.normalize` 的**输入**：`Content`、`FromUserName`、`ToUserName` 允许为 `{"string": ...}` 形状（归一器读 `{string}` 再转成纯 str） | 适配器写入 Redis `allbot` 队列的原始消息 |
| **归一结果（插件可见）** | `Content` 为**纯 `str`**；`FromUserName`/`ToUserName` 已被移除，身份改用 `FromWxid`/`ToWxid` 等标准字段 | 插件 handler 收到的 `message` |

> 二者**不矛盾**：`{"string": ...}` 是输入，`纯 str` 是输出。适配器侧文档出现的 `Content: {"string": ...}` 是合法输入形状，**不是错误**；插件侧只应依赖归一结果字段，不依赖原始协议字段。

---

## 1. 消息处理唯一路径

```
适配器原始消息
  → MessageRouter.process（utils/allbot/message_router.py）
      → MessageNormalizer.normalize（utils/message_normalizer.py）  ← 全局只调一次
  → 通用消息集
  → 按 MsgType 分发 / EventManager.emit
  → 插件
```

- 归一入口唯一：`MessageRouter.process` **只调用一次** `MessageNormalizer.normalize`。不再有「各 `process_*` 各自解析 / 二次预处理」。
- `normalize` **幂等**：命中 `_normalized` 标记即早返回；`preprocess` 仅保留空实现以兼容旧调用点。
- `utils/allbot_legacy.py` 各 `process_*` 只消费归一后的标准字段，不再重复解析协议包。
- 适配器与 legacy 链路都**不做二次解析，也不切分正文**。

## 2. 路由表与分发（`message_router.py:_route_by_type`）

| MsgType | 去向 |
|---------|------|
| `1` | 文本 |
| `3` | 图片 |
| `34` | 语音 |
| `43` | 视频 |
| `47` | 表情 |
| `49` | xml / 卡片 / 链接 / 文件 / 引用 / 小程序 |
| `10000`、`10002` | 系统 |
| `37` | `friend_request` 事件（风控 gate） |
| `51` | 明确 `pass`（协议同步状态，**不是「未知」**） |
| **其它任何 MsgType** | → `other_message` **通用出口，绝不丢弃**（`844ecb3`），经 `ignore_check` + 风控 `protector.check(14400)` gate 后 emit |

## 3. 归一后字段契约（`message_normalizer.py`）

- **`Content`：纯 `str`**（不是 `{"string": ...}`）。
- **身份 / 通用字段**：`FromWxid`（会话 ID，群聊为群 ID）、`ToWxid`、`SenderWxid`、`ActualUserWxid`、`IsGroup`、`Ats`、`MsgSource`、`platform`、`Platform`、`MsgType`、`MsgKind`、`Createtime`、`ImagePath`、`ResourcePath`、`Quote`、`Extra`、`MediaContext`、`_normalized`。
- **类型特有字段**：`AppType`、`AppKind`、`AppTitle`、`AppUrl`、`AppAttach`、`Filename`、`FileExtend`、`AttachId`、`aeskey`、`cdnmidimgurl`、`voiceurl`、`length`、`cdnvideourl`、`SysMsgType`、`Patter`、`Patted`、`PatSuffix`、`FriendRequest`。
- **`FromUserName` / `ToUserName` 在归一阶段被移除**（`_coerce_keys` 末尾 pop）：它们仅可作为归一器**输入形状**，**不是插件可见字段**。
- `MsgKind`：由 `_KIND` 表按 MsgType 产出（如 `type_XX`）；`AppKind` 由 `_APPMSG_KIND` 产出。
- `MediaContext`：框架共享下载上下文（`MediaContextRegistry`），适配器按 MsgId 消费。

## 4. 事件全集与装饰器

**14 个事件（`EventManager.emit` 分发）**：

`article_message`、`at_message`、`emoji_message`、`file_message`、`friend_request`、`image_message`、`other_message`、`pat_message`、`quote_message`、`system_message`、`text_message`、`video_message`、`voice_message`、`xml_message`

**装饰器（`utils/decorators.py`）**：`schedule` + **13 个 `on_*_message(priority=50)`**：

`on_text_message`、`on_image_message`、`on_voice_message`、`on_emoji_message`、`on_file_message`、`on_quote_message`、`on_video_message`、`on_pat_message`、`on_at_message`、`on_system_message`、`on_other_message`、`on_article_message`、`on_xml_message`

- 框架只提供上述装饰器；**不提供**命令式、调度别名、好友请求、入群之类的额外装饰器。
- `friend_request` 无对应 `on_*` 装饰器；`friend_request` / `other_message` 靠 `EventManager.emit` 分发。
- `priority` 默认 `50`，`0-99`、**越大越优先**（`utils/event_manager.py` 用 `sort(reverse=True)`）。
- 定时任务只用 `schedule`：`@schedule('interval', seconds=30)` / `@schedule('cron', hour=8)`。

## 5. 特殊规则

**群前缀剥离**：仅当 `Content` 形如 `wxid_xxx:\n`（冒号后**必须紧跟换行**）时才剥离，并作为 `SenderWxid` 兜底；`hello:world`、`https://...` 等普通正文**不切分**（修复 `e22c554`）。

**869 送达判据**：`send_text_message` 成功 = `_message_delivered`：`newMsgId>0` 且无 `isSendSuccess` 硬失败（兼容 `"false"` / `0` 字符串化值）；`ret` 非白名单只记 `problems` 供日志观测、**不否决送达**；兼容 `Data` 为 list / dict / 完整 payload 三种形状。

## 6. 插件契约

- **目录 `plugins/<Name>/`**：`main.py` **必须**（加载器只扫它）、`__init__.py` 可选（仅导出）、`config.toml` 由**插件自己**用 tomllib 读、`README.md` 可选。
- **基类 `utils/plugin_base.py`**：`class PluginBase(ABC)`；`__init__(self)` **无 bot 参数**；生命周期 `on_enable(bot=None)` / `on_disable()` / `async_init()`；基类**不提供** `self.bot` / `self.logger`（用 `from loguru import logger`）。
- **handler 固定签名** `async def handler(self, bot, message)`；返回 `True` 继续 / `False` 中断。
- **加载**：`utils/plugin_manager.py` 的 `load_plugins_from_directory` 扫 `plugins/*/main.py` → `importlib.import_module(f"plugins.{dirname}.main")` → 找 `PluginBase` 子类 → `bind_instance` → `on_enable(bot)` → `async_init()`。发现即加载，**无独立注册函数**。
- **禁用**：`main_config.toml` 的 `[AllBot] disabled-plugins`；不是各插件 `config.toml` 的 `enable`。`config.toml` 里的 `enable` 是插件自己的开关，框架不读。
- **优先级配置**：`[basic].priority` 或 `[<Name>].priority` 会被基类自动读取并 clamp 到 `0-99`（`utils/plugin_base.py:54`）。
- **发消息**：只用第 8 节 facade 承诺 API。
- **真实可跑示例**：`plugins/Protocol869Demo/main.py`、`plugins/MessageParserRecorder/main.py`（覆盖 12 类装饰器）、`plugins/README.md:25-49` 骨架。

## 7. 适配器契约

- **`adapter/base.py` 只有 `AdapterLogger` 与 `LoginCapable(Protocol)`**：没有统一适配器基类，也没有 `send_message` / `receive_message` 接口要求。
- **鸭子类型**：`class XxxAdapter:` + `def __init__(self, config_data: dict, config_path: Path)` + `def run(self)`（阻塞，独立线程，`adapter/loader.py:304,329`）；可选 `stop()`；如需被 facade 委托查询能力，提供 `get_client()` / `client` / `_bot`；如需后台登录面板，按 `LoginCapable` 结构实现 `capabilities` / `list_accounts` / `login_*`。
- **`config.toml` 三段**（模板 `adapter/web/config.toml`）：
  - `[adapter]`：`name` / `enabled` / `module` / `class` / `replyQueue` / `replyMaxRetry` …
  - `[<platform>]`：`enable` / `platform` / `aliases` / `botWxid` / `host` / `port` / `protocolVersion` …
  - `[<platform>.redis]`：`queue` / `host` / `port` / `db` / `password`
  - `enabled` + `enable` **双开关**必须一致；`module` / `class` 有默认值。敏感值一律由部署方填写，文档不写真实值。
- **入站**：`redis.rpush(queue, json.dumps(raw, ensure_ascii=False))`；框架统一归一，**适配器不要二次解析或切分正文**。最小字段 `MsgId` / `MsgType` / `Content` / `CreateTime` / `IsGroup` / `MsgSource` / `platform` / `SenderWxid` + `FromWxid|FromUserName` / `ToWxid|ToUserName`；媒体凭据可放 `Extra.<platform>.raw`。其中 `{string}` 形状属归一器输入，见「阅读前必读」。
- **出站**：`BLPOP replyQueue` → 解析 payload（`platform` / `msg_type` / `wxid` / `content` / `account_wxid`）→ 客户端 `send_*_message`。插件侧 `bot.send_text_message` → `BotFacade._send` → `ReplyRouter(allbot_reply)` → `ReplyDispatcher` → 适配器 `replyQueue`。
- **多账户**：`platform` + `account_wxid` → `utils/reply_context.py` 的 `ContextVar` + `context_resolver`；`facade._resolve_delegate` **不缓存** context 结果，避免跨账号串号。
- **自动发现**：`start_adapters` 扫 `adapter/*/config.toml`（`adapter/loader.py:73-119`），**无需改主程序**；`_resolve_upstream_settings` 从启用适配器 config 读 `host` / `port` / `protocolVersion` / `adminKey` / `wsUrl` 回写运行配置——**协议连接项归属适配器 config，不写 `main_config.toml`**。
- **现成基准**：`adapter/web/web_adapter.py`（最简）、`adapter/qq/qq_adapter.py`、`adapter/wechat_875/adapter.py`（多账户 + `LoginCapable`）。
- **排错**：日志前缀 `[Adapter:]`（`adapter/base.py:53`）。
