# AllBot 插件开发指南

本指南教你写一个能被现版框架**自动发现并加载**的插件。全部 API、字段与事件名以 [框架消息契约.md](框架消息契约.md) 为唯一事实源；本文只讲插件侧契约。

> 一句话心智模型：你把 `main.py` 放进 `plugins/<Name>/`，继承 `PluginBase`，用装饰器声明要监听的事件；框架启动时扫到它、实例化、绑定处理器、调用生命周期钩子，消息到达时按优先级把 `(bot, message)` 交给你的异步方法。

---

## 步骤 1 · 前提：确认插件未被全局禁用

框架通过 `main_config.toml` 的 `[AllBot] disabled-plugins` 决定是否跳过某个插件。写插件前，确认你的插件名不在这个列表里。

```toml
# main_config.toml（全局配置，按仓库实际键名填写）
[AllBot]
disabled-plugins = ["OtherPlugin"]   # 只要 MyPlugin 不在此列表中即可
```

注意：**插件 `config.toml` 里的 `enable` 不是框架开关**。框架不读取它，它是插件自己 `tomllib` 读取的业务开关（见步骤 7）。真正决定「加不加载」的只有 `disabled-plugins`。

---

## 步骤 2 · 目录结构：`main.py` 必须

每个插件是 `plugins/` 下的一个目录：

```text
plugins/MyPlugin/
├── main.py          # 必须：插件类定义，加载器只扫这个文件
├── __init__.py      # 可选：仅做导出（如 from .main import MyPlugin）
├── config.toml      # 可选：由插件自己用 tomllib 读取
└── README.md        # 可选：插件说明
```

- **`main.py` 必须存在**：加载器 `load_plugins_from_directory` 只检查 `plugins/*/main.py`，没有它就不会被发现。
- **`__init__.py` 不是入口**，只是可选的导出文件；把插件类写在 `__init__.py` 里不会被加载。
- **`config.toml` 由插件自己读**：框架不替你解析业务配置，只自动读取其中的 `priority`（见步骤 7）。

现成参考：`plugins/Protocol869Demo/`（真实可跑示例）、`plugins/MessageParserRecorder/main.py`（覆盖 12 类装饰器）。

## 步骤 3 · 最小骨架：`PluginBase` + 无参 `__init__`

```python
# plugins/MyPlugin/main.py
from loguru import logger
from utils.plugin_base import PluginBase
from utils.decorators import on_text_message


class MyPlugin(PluginBase):
    description = "我的第一个插件"
    author = "your-name"
    version = "1.0.0"

    def __init__(self):
        super().__init__()          # 无 bot 参数；基类会读取 config.toml 的 priority
        self.bot = None             # 基类不提供 self.bot / self.logger，需要就自己存

    async def on_enable(self, bot=None):
        self.bot = bot              # 需要长期持有 bot 就在这里自存
        await super().on_enable(bot)  # 必须调用：基类在此注册 @schedule 定时任务
        logger.info("MyPlugin 已启用")

    async def on_disable(self):
        await super().on_disable()    # 必须调用：基类在此卸载定时任务
        logger.info("MyPlugin 已停用")

    async def async_init(self):
        return                      # 需要异步初始化（建连接、拉数据）时在这里做
```

要点，逐条对齐现版基类（`utils/plugin_base.py`）：

- 基类是 `class PluginBase(ABC)`，从 `utils.plugin_base import PluginBase`。
- `__init__(self)` **没有 bot 参数**；`bot` 在 `on_enable(self, bot=None)` 里传入。
- 基类**不提供** `self.bot` 和 `self.logger`：日志用 `from loguru import logger`，要用 bot 就在 `on_enable` 里自己存。
- 生命周期钩子是 `on_enable(bot=None)` / `on_disable()` / `async_init()`，三者都是 `async`。
- 若重写 `on_enable` / `on_disable`，**务必 `await super().…(bot)`**，否则 `@schedule` 定时任务不会被注册/卸载。

## 步骤 4 · 事件处理器：固定签名 + 14 事件 + 优先级

处理器签名固定为 `async def handler(self, bot, message)`，用装饰器声明监听哪个事件：

```python
from utils.decorators import on_text_message

class MyPlugin(PluginBase):
    @on_text_message(priority=60)
    async def handle_text(self, bot, message):
        # message 是框架统一归一后的字典（见步骤 5）
        return True   # True：把消息继续交给后续处理器；False：中断本次分发
```

**14 个事件全集**（`utils/event_manager.py` 分发）：

| 事件 | 含义 | 是否有 `on_*` 装饰器 |
|---|---|---|
| `text_message` | 文本 | `@on_text_message` |
| `image_message` | 图片 | `@on_image_message` |
| `voice_message` | 语音 | `@on_voice_message` |
| `video_message` | 视频 | `@on_video_message` |
| `emoji_message` | 表情 | `@on_emoji_message` |
| `file_message` | 文件 | `@on_file_message` |
| `at_message` | 被 @ | `@on_at_message` |
| `quote_message` | 引用/回复 | `@on_quote_message` |
| `pat_message` | 拍一拍 | `@on_pat_message` |
| `system_message` | 系统消息 | `@on_system_message` |
| `article_message` | 公众号文章 | `@on_article_message` |
| `xml_message` | XML / 卡片 / 链接 / 小程序 | `@on_xml_message` |
| `other_message` | 其它任何 MsgType 的通用出口（不丢弃） | `@on_other_message` |
| `friend_request` | 好友请求 | **无装饰器**，靠 `EventManager.emit` 分发 |

`utils/decorators.py` 提供 `schedule` + **13 个** `on_*_message(priority=50)` 装饰器。框架只提供上表的事件装饰器与 `schedule`，没有旧版的命令装饰器、定时装饰器或私聊/群聊生命周期钩子。

**优先级规则**：`priority` 取 `0-99`，**数值越大越优先**（`utils/event_manager.py` 用 `sort(..., reverse=True)`），默认 `50`。返回 `True` 让后续处理器继续执行，返回 `False` 中断本次事件分发；返回非布尔值也会继续。

## 步骤 5 · 消息字段契约：拿到的是归一结果

处理器收到的 `message` 是框架统一归一后的字典。记住三条：

- **`Content` 是纯 `str`**，不是 `{"string": ...}` 这类对象，可直接 `.strip()` / `.startswith()`。
- 用 **`FromWxid`**（会话 ID，群聊时为群 ID）、**`SenderWxid`**（群内真实发送者）、**`MsgKind`** / **`MsgType`** / **`platform`** / **`Ats`** / **`Quote`** / **`MediaContext`** / **`_normalized`** 等字段。
- 归一器输入侧的用户名字段与旧版小写键名在归一阶段已全部移除，插件侧不可见；一律使用上表的标准字段。

常用字段一览（身份/通用）：`FromWxid`、`ToWxid`、`SenderWxid`、`ActualUserWxid`、`IsGroup`、`Ats`、`MsgSource`、`platform`、`Platform`、`MsgType`、`MsgKind`、`Createtime`、`ImagePath`、`ResourcePath`、`Quote`、`Extra`、`MediaContext`、`_normalized`。类型特有字段如 `AppType` / `AppKind` / `AppTitle` / `AppUrl` / `Filename` / `FileExtend` / `AttachId` / `aeskey` / `voiceurl` / `cdnvideourl` / `SysMsgType` / `Patter` / `Patted` / `PatSuffix` / `FriendRequest` 等按消息类型出现。

> 适配器入队时、归一器**输入形状**里允许 `Content: {"string": ...}` 这类包装，框架统一归一后再转成纯 `str`；插件可见的是**归一结果**。二者不矛盾，完整字段表与路由表见 [框架消息契约.md](框架消息契约.md)。

## 步骤 6 · 发消息：只用 facade 承诺的 API

`bot` 是协议无关门面（`WechatAPI/facade.py` 的 `WechatAPIClient`）。发消息/下载只用下列已承诺方法：

**发送类**
```text
send_text_message(wxid, content, at="")   # 主推；send_text 是其别名
send_at_message / send_image_message / send_voice_message / send_video_message
send_file_message / send_link_message / send_card_message / send_emoji_message
send_app_message / send_cdn_file_msg / send_cdn_img_msg / send_cdn_video_msg
revoke_message / send_pat
```

**下载与工具类**
```text
get_msg_image / download_image / download_voice / download_video
download_attach / download_emoji / download_file / upload_file
silk_base64_to_wav_byte / silk_byte_to_byte_wav_byte
get_contract_detail / get_contract_list / get_pyq_list / get_pyq_detail / put_pyq_comment
```

```python
@on_text_message(priority=60)
async def handle_text(self, bot, message):
    conv = message.get("FromWxid", "")
    if message.get("Content", "").strip() == "你好":
        await bot.send_text_message(conv, "你好！")
        return False
    return True
```

**只使用上表中 facade 已承诺的 `send_*_message` 系列**，不要用任何未带 `_message` 后缀或不在清单内的发送名：门面虽有 `__getattr__` 转发，但不保证可用。

## 步骤 7 · 配置：`priority` 归框架，`enable` 归插件自己

```toml
# plugins/MyPlugin/config.toml —— 由插件自己用 tomllib 读取
[basic]
priority = 60          # 全局优先级：基类自动读取并 clamp 到 0-99

[MyPlugin]
enable = true          # 插件自己的业务开关，框架不读取
```

- **优先级**：基类 `PluginBase.__init__` 会尝试从 `[basic].priority` 或 `[MyPlugin].priority` 读取全局优先级，`min(max(x, 0), 99)` 后写入 `self.priority` 并置 `has_global_priority=True`。此时全局优先级会**覆盖**装饰器上的 `priority`；未配置则用装饰器的值。
- **`enable` 归属**：框架不读 `enable`。想让开关生效，插件自己读：

```python
import tomllib
from pathlib import Path

def _load_enable(self) -> bool:
    try:
        with open(Path(__file__).parent / "config.toml", "rb") as f:
            cfg = tomllib.load(f)
        return bool(cfg.get("MyPlugin", {}).get("enable", True))
    except Exception:
        return True
```

- **禁用**只走 `main_config.toml` 的 `[AllBot] disabled-plugins`（见步骤 1）。

## 步骤 8 · 定时任务：`schedule` 装饰器

```python
from utils.decorators import schedule

class MyPlugin(PluginBase):
    @schedule('interval', seconds=30)
    async def tick(self, bot):
        # 每 30 秒执行一次；bot 由基类注册任务时注入
        ...

    @schedule('cron', hour=8)
    async def morning(self, bot):
        # 每天 8 点执行
        ...
```

- 从 `utils.decorators import schedule`，用 `@schedule('interval', seconds=30)` 或 `@schedule('cron', hour=8)`；也支持 `'date'` 触发器。
- 任务函数签名是 `async def xxx(self, bot)`。
- 基类在 `on_enable` 里扫描带 `_is_scheduled` 标记的方法自动注册，在 `on_disable` 里自动卸载——所以**重写生命周期时必须 `await super()`**（见步骤 3）。
- 定时任务装饰器只有 `schedule` 一种。

## 步骤 9 · 加载与发现：框架自动完成，无需注册

`utils/plugin_manager.py` 的 `load_plugins_from_directory` 流程：

1. 遍历 `plugins/` 子目录，**只挑出含 `main.py` 的目录**；
2. `importlib.import_module(f"plugins.{dirname}.main")` 导入模块；
3. 用 `inspect.getmembers` 找出 `PluginBase` 的子类（排除基类本身）；
4. 对每个子类 `load_plugin`：实例化 → `EventManager.bind_instance(plugin)` 绑定所有带 `_event_type` 标记的处理器 → `await plugin.on_enable(bot)` → `await plugin.async_init()`。

**框架自动发现，无需任何手动注册代码。** 你只要把类放进 `main.py`，框架就能发现它。被 `[AllBot] disabled-plugins` 命中的插件会跳过实例化。

---

## 步骤 10 · 启动框架

1. 把 `plugins/MyPlugin/` 放进 `plugins/` 下，确认 `main.py` 存在且类名/目录名无误。
2. 确认 `main_config.toml` 的 `[AllBot] disabled-plugins` 不含 `MyPlugin`。
3. 按仓库既有部署方式启动框架。框架在 `bot` 客户端就绪后自动调用 `PluginManager.load_plugins_from_directory(bot)` 批量加载，你不需要改动任何主程序。

## 步骤 11 · 验证与排错

启动时观察日志（均为框架真实打印的文本）：

| 现象 | 去哪查 |
|---|---|
| 加载成功 | `加载插件 MyPlugin，使用全局优先级: 60` 或 `加载插件 MyPlugin，使用装饰器优先级` |
| 定时任务生效 | `插件 MyPlugin 已加载定时任务: {...}` |
| 加载失败 | `加载插件时发生错误: ...`（含 traceback）或 `加载 MyPlugin 时发生错误: ...` |
| 处理器抛异常 | `事件处理器执行异常(event=text_message, handler=MyPlugin.handle_text): ...` |

排错顺序：先确认出现了「加载插件」日志 → 再确认定时任务日志（若有）→ 发一条触发消息看是否进 handler → 若 handler 报错，看「事件处理器执行异常」里的异常栈。若完全没有「加载插件」日志，多半是 `main.py` 缺失、类未继承 `PluginBase`、或插件名被写进了 `disabled-plugins`。

## 步骤 12 · 常见坑

| 坑 | 正确做法 |
|---|---|
| 把类写在 `__init__.py` 当入口 | 写在 `main.py`；`__init__.py` 只做可选导出 |
| `def __init__(self, bot)` 带 bot 参数 | `__init__(self)` 无参；bot 在 `on_enable(self, bot)` 拿 |
| 直接用 `self.bot` / `self.logger` | 基类不提供；日志用 `loguru.logger`，bot 在 `on_enable` 自存 |
| 用旧版小写键名取值 | 用 `FromWxid` / `Content`（纯 str）/ `SenderWxid`；详见 [框架消息契约.md](框架消息契约.md) |
| 用归一器输入侧的用户名字段 | 归一阶段已移除，插件侧不存在 |
| 用未承诺的发送方法名 | 用 facade 承诺的 `send_*_message` 系列 |
| 以 `enable = false` 就能让框架不加载 | 框架不读 `enable`；禁用只走 `[AllBot] disabled-plugins` |
| 重写 `on_enable`/`on_disable` 忘了 `await super()` | 会导致 `@schedule` 定时任务不注册/不卸载 |
| 以为 `priority` 越小越优先 | 越大越优先（0-99，`sort(reverse=True)`） |
| 沿用旧版命令/定时装饰器、手动注册函数或旧生命周期钩子 | 这些写法现版均不支持，按本指南用 `on_*_message` + `schedule` + 自动发现 |
| handler 里随手 `return False` | `False` 会中断同事件后续所有处理器，确认要独占时才用 |

## 附录：完整可跑示例

参照 `plugins/Protocol869Demo/main.py` 的真实写法。这个类放进 `plugins/EchoDemo/main.py` 后能被框架直接发现并加载。

```python
# plugins/EchoDemo/main.py
from __future__ import annotations

import tomllib
from pathlib import Path
from typing import Any, Dict

from loguru import logger
from WechatAPI import WechatAPIClient

from utils.decorators import on_text_message, schedule
from utils.plugin_base import PluginBase


def _safe_text(value: Any) -> str:
    """兼容归一结果（纯 str）与个别历史形状，稳妥取文本。"""
    if value is None:
        return ""
    if isinstance(value, dict):
        return str(value.get("string", ""))
    return str(value)


class EchoDemo(PluginBase):
    description = "回声示例：回复文本 + 每 30 秒记录一次心跳"
    author = "your-name"
    version = "1.0.0"

    def __init__(self):
        super().__init__()
        self.bot: WechatAPIClient | None = None
        self.enable = self._load_enable()
        self.ticks = 0

    @staticmethod
    def _load_enable() -> bool:
        try:
            with open(Path(__file__).parent / "config.toml", "rb") as f:
                cfg = tomllib.load(f)
            return bool(cfg.get("EchoDemo", {}).get("enable", True))
        except Exception:
            return True

    async def on_enable(self, bot=None):
        self.bot = bot
        await super().on_enable(bot)   # 注册 @schedule 任务
        logger.info("[EchoDemo] 已启用, enable={}", self.enable)

    async def on_disable(self):
        await super().on_disable()     # 卸载 @schedule 任务
        logger.info("[EchoDemo] 已停用")

    @on_text_message(priority=60)
    async def handle_text(self, bot: WechatAPIClient, message: Dict[str, Any]) -> bool:
        if not self.enable:
            return True

        content = _safe_text(message.get("Content")).strip()
        if not content.startswith("回声:"):
            return True

        reply = content[len("回声:"):].strip()
        conv = _safe_text(message.get("FromWxid")).strip()
        if reply and conv:
            await bot.send_text_message(conv, f"回声: {reply}")
        return False                  # 本命令已处理，中断后续处理器

    @schedule('interval', seconds=30)
    async def heartbeat(self, bot: WechatAPIClient):
        self.ticks += 1
        logger.debug("[EchoDemo] heartbeat #{}", self.ticks)
```

配套 `plugins/EchoDemo/config.toml`：

```toml
[basic]
priority = 60        # 基类自动读取并 clamp 到 0-99

[EchoDemo]
enable = true        # 插件自己的开关，框架不读取
```

核对：本示例用到的 `PluginBase`、`on_text_message`、`schedule`、`loguru.logger`、`WechatAPIClient`、`send_text_message`、`FromWxid`、`Content`、`on_enable` / `on_disable`、`tomllib` 全部来自现版框架；不含旧版注册函数、旧版命令/定时装饰器、`self.logger` 或任何未承诺的发送方法名。
