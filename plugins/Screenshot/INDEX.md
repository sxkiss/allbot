# Screenshot

基于 screenshotsnap API 的网页截图插件：`截图` + URL，支持引用消息提取链接。

## Files

| File | Role | Function |
|------|------|----------|
| main.py | Plugin | 文本/引用消息触发截图并发送图片（与 Typhoon 同接口） |
| config.toml | Config | 开关、命令词、分辨率、超时与 API 地址 |
| __init__.py | Export | 导出 Screenshot |
| README.md | Doc | 使用说明 |
